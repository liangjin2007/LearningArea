## Spin Images [1999][PAMI]https://www-robotics.jpl.nasa.gov/media/documents/aejPAMI1999.pdf
```
论文标题：Using Spin-Images for Efficient Object Recognition in Cluttered 3-D Scenes
主要思路：
  vertex position + normal -> construct 2-D images associated with each point
    构造local basis
    将周围点的位置用2个参数方向(ui, vi, height_i)表示出来。
    算2D-直方图
应用：图像层面的template matching或者pattern classification
```
